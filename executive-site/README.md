# Executive-лендинг Валерия Григорчука — резерв для Timeweb Cloud

Каталог `executive-site/` содержит автономный статический сайт, перенесённый из действующей публикации Vercel.

## Параметры App Platform

- Репозиторий: `piobeat-ux/piobeat`
- Ветка: `timeweb-executive` (основную ветку `main` не менять)
- Путь до директории проекта: `executive-site`
- Тип приложения: **HTML/CSS/JS** (готовые статические файлы)
- Команда сборки: **не нужна**
- Команда запуска: **не нужна**
- Автодеплой: включить для этой ветки
- Тестировать сначала на техническом домене Timeweb Cloud с HTTPS.

## Структура

- `index.html` — опубликованный executive-лендинг с адаптивной вёрсткой
- `portrait.webp` — локальная оптимизированная фотография, без обращений к Vercel
- `cv.html` — дополнительная онлайн-версия полного CV (резервный маршрут)

Кнопка «Полное резюме PDF» на главной странице ведёт на Яндекс Диск:
https://disk.yandex.ru/i/kjXQV89_2f15mg

## Переключение домена

После проверки мобильных сетей и браузеров добавить внешний домен `cv.vgrigorchuk.ru` в настройки Timeweb. В DNS REG.RU изменить **только запись поддомена cv** на значение, которое выдаст Timeweb. Не менять NS, MX, DKIM, SPF и другие записи почты.

Vercel остаётся доступной резервной публикацией до завершения миграции.

## Контроль качества

Проверить страницы `/` и `/cv.html`, портрет `/portrait.webp`, ссылки `mailto:`, `tel:` и Яндекс Диск. Проверить отсутствие горизонтальной прокрутки на ширинах 320, 375, 390, 430 и 768 px.

Содержимое сайта уже публичное. Не добавлять сюда внутренние финансовые данные текущего корпоративного заказчика.
