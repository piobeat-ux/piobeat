## 🚀 Быстрая установка (3 шага)

### Шаг 1: Создайте репозиторий на GitHub

1. Перейдите на [github.com/new](https://github.com/new)
2. В поле **"Repository name"** введите: `pio-beat-website`
3. Выберите **"Public"** (обязательно для GitHub Pages)
4. Нажмите **"Create repository"**

### Шаг 2: Загрузите файлы

1. Откройте ваш новый репозиторий
2. Нажмите **"Add file"** → **"Upload files"**
3. Перетащите ВСЕ файлы из этой папки:
   - `index.html`
   - папку `assets/`
   - папку `merch/`
   - папку `.github/`
   - `README.md`
   - `GITHUB_DEPLOY_GUIDE.md`
4. Нажмите **"Commit changes"**

### Шаг 3: Включите GitHub Pages

1. В репозитории перейдите во вкладку **"Settings"**
2. В левом меню выберите **"Pages"**
3. В разделе **"Build and deployment"** выберите **"GitHub Actions"**
4. Нажмите **"Save"**

Готово! Сайт будет доступен через 2-3 минуты по адресу:
`https://your-username.github.io/pio-beat-website`

## 🔧 Устранение неполадок

### Сайт не отображается (404)
- Подождите 5 минут после загрузки
- Проверьте, что репозиторий публичный
- Проверьте вкладку "Actions" на ошибки

### Не загружаются картинки
- Убедитесь, что папка `merch/` загружена
- Проверьте расширения файлов (.jpg)
